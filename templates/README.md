# `templates/` — plantillas para repos consumidores

| Archivo | Uso |
|---------|-----|
| `QRD.md` | Esqueleto del documento de requisitos de QA. |
| `manifest.template.json` | Base para `qa.json`. |
| `pilot-admission.md` | Checklist antes de adoptar el harness en un producto. |
| `sql-profile.template.json` | Perfil SQL opcional en el consumidor. |

Copiar y adaptar en el repo del producto; no editar las plantillas in-place para un cliente concreto.
